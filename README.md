# Ironfield RTS

一个独立的单机 RTS 战斗原型。当前版本只聚焦核心交战：选兵、编队移动、指定集火、兵种克制与胜负结算，不包含市场、经济、建造或联网系统。

## 启动

```bash
pnpm install
pnpm dev
```

默认开发地址为 `http://127.0.0.1:5174/`。

## 操作

- 左键点击或拖框：选择翠绿军团
- `Shift` + 左键：增减选择
- 右键地面：编队移动
- 右键敌军：指定集火
- `A`：切换攻击移动；`S`：停止；`H`：坚守
- 方向键：平移视野；中键拖动或 `Q` / `E`：旋转镜头
- 鼠标滚轮：缩放

## 当前战斗规则

- 盾锋骑士：高生命、近战阻挡
- 长弓游侠：远距离单体输出
- 奥术法师：远距离范围伤害
- 默认规模为 40v40，每方由两支骑士、两支游侠和一支法师小队组成
- 远程攻击使用权威投射物与战斗事件，在命中时结算伤害
- 猩红军团在短暂列阵后由本地 AI 自动推进
- 单局消灭对方全部单位后结算，可立即重新列阵

战斗模拟位于 `src/game`，Three.js 场景位于 `src/scene`，界面与输入协调位于 `src/App.tsx`。模拟规则不依赖渲染层，可以单独测试。

## 美术资源

项目复用了原工作区里的 KayKit 低多边形资源，并已复制到本项目的 `public/assets/kaykit`，因此运行时不依赖原项目目录。各资源包的原始 `LICENSE.txt` 均随文件保留。

## 验证

```bash
pnpm check
```

该命令会依次执行 ESLint、TypeScript 类型检查、Vitest 和生产构建。
