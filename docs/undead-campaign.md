# 亡灵战役设计：无名者之誓

## 定位

亡灵战役是人族战役的地下并行线，而不是同一套关卡的种族换皮。

苍蓝联军北进之时，猩红王室直属的黎明教团正沿旧战线掘墓，以终墓之钥抽取亡魂，供养黑墙与王城的永昼圣火。被夺去名字的死者在墓下结成无名王庭，沿着地表战争留下的裂隙夺回自己的安息。

两条战役在同一夜结束：苍蓝联军熄灭城上的猩红旗，无名王庭熄灭城下的永昼火。

## 设计支柱

### 1. 数量不是耐久

骸骨先锋一次召来五只，但单体极其脆弱。玩家需要错开召唤，让新一批骨潮在上一批瓦解前接战，而不是把它当作人族长枪兵使用。

### 2. 极端单位互相补位

- 骸骨先锋：低费、快速、数量多，用于聚敌和填补战线。
- 骸骨弩手：射程很远、射击较慢，需要前排制造安全距离。
- 亡魂术士：射程较短、快速大范围攻击，是早期亡灵核心。
- 墓穴卫士：只有一名、移动缓慢，却是最可靠的重甲锚点。
- 冰霜骨龙：地面重甲单位，以锥形吐息覆盖密集目标；没有飞行、冻结或减速能力。

### 3. 不死军势来自节奏

诅咒晶矿提供长期军费，墓穴兵营以较慢周期召来墓穴卫士，魂火尖塔只能短暂封锁一路。亡灵的持续作战能力来自部署时机与路线选择，而不是复活阵亡单位。

## 关卡结构

战役保留与人族线一致的可读结构：8 个主线任务、6 个可选冥契仪式、共 14 个节点。冥契仪式临时借用一种军备，首次完成后只在亡灵战役中永久解锁。

| 1 | 墓园苏醒 | 主线 | 死者初醒 | 简单 / 500 | 用骨潮聚敌、用超远弩手输出；终墓之钥被盗 | — |

亡灵冥契的解锁顺序刻意区别于人族：

1. 亡魂术士
2. 墓穴卫士
3. 诅咒晶矿
4. 墓穴兵营
5. 魂火尖塔
6. 冰霜骨龙

这样会先建立“骨潮聚敌 + 范围清场”的种族核心，再补足重甲、经济、持续增援和后期破阵能力。

## 星级目标

每关通关获得一星，两个可选目标各提供一星。大部分关卡沿用限时与城堡生命目标；三个骨潮主线改用“至少召唤若干批骸骨先锋”，让评分系统直接强调亡灵的部署节奏。

- 死者初醒：150 秒内获胜；至少召唤 3 批骸骨先锋。
- 灰河无渡：145 秒内获胜；至少召唤 4 批骸骨先锋。
- 白骨潮汐：130 秒内获胜；至少召唤 5 批骸骨先锋。

冥契仪式除胜利外，还会硬性检查本关借用军备是否至少部署一次。

## 系统映射

亡灵战役继续使用玩家 `verdant`、AI `crimson` 的底层阵营关系，但种族配置为：

```ts
{
  verdant: "undead",
  crimson: "human",
}
```

这种做法无需改变部署区域、AI 所属方、胜负结算或摄像机方向，同时会自动启用亡灵单位、建筑、地貌、动画、音效和特效。

战役进度仍存放在 `ironfield.campaign-progress.v1`。人族任务保留原 ID，亡灵任务使用 `undead-*` 前缀，因此旧存档无需迁移；军备解锁会按战役过滤，不会跨种族串线。

## 术语规范

- 使用“骨潮”，不使用“尸潮”；当前阵容没有僵尸。
- 亡灵支线统一称“冥契仪式”。
- 正式单位名：骸骨先锋、墓穴卫士、骸骨弩手、亡魂术士、冰霜骨龙。
- 正式建筑名：魂火尖塔、诅咒晶矿、墓穴兵营。
- 黎明教团是猩红王室直属军团，避免与红色人类模型和人族战役冲突。
- 永昼圣堂位于猩红王城地下，不是第二座独立城市。
- HUD 经济资源继续称“金币 / 储备 / 军费”，不把同一数值另称为灵质。

## 当前实现边界

当前任务系统能够可靠判定：战斗胜利、限时、己方城堡生命、累计部署次数，以及冥契军备是否至少部署一次。

以下内容目前只作为叙事包装，不声称已经具备独立玩法判定：指定桥梁、夺取物品、摧毁特定经济建筑、英雄、复活、尸体转化、飞行、冰冻、护送、占点或脚本增援。若后续加入任务脚本层，再把真名石板、魂炉与终墓之钥升级为场景目标。

## 平衡验证重点

- 骸骨先锋单体存活率很低，三星部署数量目标需实机确认不会诱导无意义送兵。
- 亡魂术士提前解锁后，前两章的范围清场速度可能显著高于人族战役。
- 墓穴兵营需要 700 金币，试炼给 900 金是为了让玩家仍能保留一批基础部队应对开局。
- 冰霜骨龙是地面锥形范围单位；关卡文案和后续特效不得暗示飞行或减速。
- 玩家固定在 `verdant` 一侧，地图侧向优势可能影响所有限时星级阈值，最终数值应以批量模拟和实机试玩共同校准。
