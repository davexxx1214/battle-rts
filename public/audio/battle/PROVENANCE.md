# Battle audio provenance

All WAV files in this directory were generated specifically for Ironfield RTS with Fal model `sonilo/v1.1/text-to-sound-effects`. They were not downloaded from a CC0 recording library and are not represented here as CC0 assets.

The exact model name, prompt, requested duration, Fal request ID, output filename, and SHA-256 checksum for every file are recorded in [`audio/battle-sfx.provenance.json`](../../../audio/battle-sfx.provenance.json). Runtime event mappings and concurrency limits are recorded in [`cues.json`](./cues.json).

Fal labels the model output as commercial-use-safe on the [model API page](https://fal.ai/models/sonilo/v1.1/text-to-sound-effects/api). Use of generated output remains subject to [Fal's Terms of Service](https://fal.ai/legal/terms-of-service), applicable law, and any project-specific legal review.

The Fal API key is used only by the local generation script. It is not copied into this public directory or shipped to the browser.
